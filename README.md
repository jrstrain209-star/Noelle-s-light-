# Noelle’s Light

A calm, mobile-first memorial and peer-support website prototype built for Vercel.

## Deploy on Vercel

1. Go to Vercel.com and sign in.
2. Choose **Add New Project**.
3. Upload this project folder, or import it from GitHub.
4. Vercel should detect it as a Next.js app automatically.
5. Click **Deploy**.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000
